Full Design Overview

Here's the complete picture before we dive into details. I'll walk through each section.

1. Frontend Architecture

  • Layout: Top bar (brand + user menu) + collapsible sidebar (nav links)
  • Dark/Light: Toggle with system preference detection, persisted
  • Pages: Dashboard, Login, Settings, Analytics (per-link)
  • Create Link: Slide-over panel from dashboard
  • Charts: Recharts library for analytics visualizations

2. Analytics Pipeline

  • Tracking: Redirection service publishes click events to Redis Stream
  • Processing: Dedicated consumer reads stream, parses UA, resolves geo, deduplicates
  • Storage: New clicks table in PostgreSQL
  • Query API: API service exposes aggregated stats endpoints

3. Data Model

  • clicks table: id, link_id, timestamp, ip, user_agent, referrer, country, city, device_type, browser, is_unique
  • Aggregated via SQL queries with time-bucket grouping

4. Order of Implementation

  1. Frontend: navigation layout + auth pages
  2. Frontend: dashboard with link management (CRUD)
  3. Analytics: clicks table + Redis stream publishing in redirection service
  4. Analytics: consumer service + API endpoints
  5. Frontend: analytics charts on the dashboard
  6. Frontend: settings page
