Section 3: Analytics Pipeline

Event-driven with Redis Streams — data flow

User clicks short link
↓
Redirection Service resolves & redirects (302)
↓ (fire & forget)
Publishes event to Redis Stream: {link_id, ip, user_agent, referrer, timestamp}
↓
Analytics Consumer reads stream in batches
↓
Parses user-agent → ua-parser-js → browser, OS, device type
↓
Resolves IP → geolocation via maxmind GeoLite2 or free API
↓
Deduplicates: same IP + link_id within 1 hour → not unique
↓
Writes row to clicks table in PostgreSQL
  • Consumer location: New analytics-consumer/ directory under project root
  • API endpoints (on API service): GET /api/v1/links/:id/analytics returning pre-aggregated stats
  • No blocking: Redirect happens before the event is published — zero latency impact
