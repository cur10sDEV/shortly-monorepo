Frontend Scope

What pages/sections do you want in the Shortly frontend?

1

Dashboard / Link Manager

Main page showing all your shortened links with search, filter, and pagination

2

Create Link Form

Page or modal to create a new shortened URL (long URL, optional password, optional expiry)

3

Link Analytics / Stats

Per-link analytics page showing clicks over time, referrers, browsers, locations

4

Login / Auth Page

Dedicated login page with Google sign-in, not just a button on the home page

5

Settings / Profile Page

User profile, preferences, API keys, account management
