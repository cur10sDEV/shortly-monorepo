Create Link Flow

How should users create a new short URL?

A

Modal / Slide-over Panel

Click "Create Link" button, a panel slides in from the right. Stay on the dashboard, fill the form, submit, see the new link appear. No page navigation.

B

Dedicated Page

Navigate to /links/new for a full-page form. More room for options, better for complex forms.

C

Quick-create on Dashboard

An input bar at the top of the dashboard — just paste a URL and hit enter. For advanced options, opens a modal.
