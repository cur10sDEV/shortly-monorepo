Navigation Layout

How should the app navigation work?

A

Sidebar Navigation

Persistent sidebar on the left with all nav links. Main content on the right. Collapsible on mobile.

B

Top Navigation Bar

Nav links in a top bar with user avatar/name on the right. Page content fills below.

C

Hybrid — Top Bar + Sidebar

Top bar with branding + user menu. Sidebar with page navigation links. More complex but feature-rich.
