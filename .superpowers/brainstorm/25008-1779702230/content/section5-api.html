Section 5: API Endpoints — Analytics

New endpoints on the API service for querying stats

GET /api/v1/links/:id/analytics/summary
→ { total_clicks, unique_clicks, last_click_at }

GET /api/v1/links/:id/analytics/timeline
?from=2026-05-01&to=2026-05-25&bucket=day
→ [{ date, clicks, unique_clicks }, ...]

GET /api/v1/links/:id/analytics/referrers
→ [{ source, clicks, percentage }, ...]

GET /api/v1/links/:id/analytics/devices
→ [{ device_type, clicks }, { browser, clicks }, { os, clicks }]

GET /api/v1/links/:id/analytics/locations
→ [{ country, city, clicks }, ...]
  • All endpoints require auth (user must own the link)
  • All accept optional from/to date filters
  • Responses are aggregated via SQL — no pre-computation needed initially
