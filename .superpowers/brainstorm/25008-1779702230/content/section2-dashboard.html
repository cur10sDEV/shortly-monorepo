Section 2: Dashboard / Link Manager

The core page users see after login

  • Quick-create bar at the top — paste a long URL, hit enter, instantly get a short link. Opens the full slide-over panel for advanced options.
  • Link list in a table/card layout showing: short code, long URL (truncated), click count, created date, status (active/expired), actions
  • Pagination via keyset-based (cursor) pagination matching the backend API
  • Row actions: Copy short URL, View analytics, Edit (opens slide-over), Delete (soft-delete with confirmation)
  • Empty state: Illustration + "Create your first short link" CTA when user has no links
