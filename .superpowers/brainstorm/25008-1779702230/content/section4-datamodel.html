Section 4: Data Model — Clicks Table

New table in PostgreSQL for analytics

CREATE TABLE IF NOT EXISTS "clicks" (
  "id" BIGSERIAL PRIMARY KEY,
  "link_id" INTEGER NOT NULL REFERENCES "links"("id") ON DELETE CASCADE,
  "timestamp" TIMESTAMPTZ NOT NULL DEFAULT now(),
  "ip" VARCHAR(45),
  "user_agent" TEXT,
  "referrer" TEXT,
  "country" VARCHAR(100),
  "city" VARCHAR(100),
  "browser" VARCHAR(50),
  "os" VARCHAR(50),
  "device_type" VARCHAR(20),
  "is_unique" BOOLEAN DEFAULT true
);

CREATE INDEX idx_clicks_link_id ON "clicks" ("link_id");
CREATE INDEX idx_clicks_timestamp ON "clicks" ("timestamp");
CREATE INDEX idx_clicks_link_timestamp ON "clicks" ("link_id", "timestamp");
  • link_id — FK to links table for JOIN queries
  • ip — stored for dedup, not exposed to users
  • country/city — resolved from IP at write time
  • browser/os/device_type — parsed from user-agent at write time
  • is_unique — if same IP + link_id within 1hr, marked false
  • 3 indexes — for common query patterns (by link, by time, by link+time)
